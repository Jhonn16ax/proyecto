# Proyecto 1 - Laboratorio 3

## Runner
Aplicación interactiva sencilla desarrollada con HTML, CSS y JavaScript.

### Propósito
Crear un juego de carrera en el que el personaje avance hacia la derecha, salte obstáculos y recoja anillos.

### Interacción
- Empezar el juego.
- Saltar con el botón o con ESPACIO / flecha arriba.
- Recoger anillos para aumentar el contador.
- Evitar obstáculos.
- Si el personaje choca, la partida se reinicia.
- Reiniciar manualmente con el botón Reiniciar.

### Tecnologías
HTML, CSS y JavaScript. No utiliza base de datos, backend, APIs externas ni frameworks.

### Estado de la entrega
Checkpoint del Proyecto 1 correspondiente al Laboratorio 3.
